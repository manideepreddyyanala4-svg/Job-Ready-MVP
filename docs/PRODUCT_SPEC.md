# JobReady V0 product specification

JobReady helps Indian college students understand which career evidence is missing before applying, then build that evidence through a guided project. The V0 funnel is landing page → demo/auth → onboarding → resume baseline → readiness report → role matches → gaps → project recommendation → Mission 1 → paid workspace.

Scores describe visible readiness and role alignment. They are never presented as a probability of employment. A missing resume keyword is an evidence gap, not proof the student does not know a skill.
