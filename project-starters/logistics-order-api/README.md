# Logistics Order API starter

This is a deliberately incomplete starter repository for the Production Backend System project.

## Goal

Build a service for customers, orders, shipments, and delivery status transitions. The student is expected to make the design decisions, implement the rules, and add the evidence described in the project rubric.

## Suggested sequence

1. Write the domain brief and non-goals.
2. Define the data model and migrations.
3. Add a versioned API boundary.
4. Add authentication and ownership checks.
5. Implement and test status transitions.
6. Add operational documentation, Docker, and deployment notes.

Do not treat this starter as a reference implementation. It intentionally contains no completed business logic.
